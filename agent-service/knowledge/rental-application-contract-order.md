# 租房申请、合同与订单

## 提交租房申请

租客只能申请已通过审核且当前状态为可租的房源，不能申请自己发布的房源。对同一房源已有待处理或已通过申请时不能重复提交。申请提交后的初始状态为待审核。

## 房东审核申请

房东只能审核自己房源的申请，可以通过或拒绝待审核申请。一个房源只能通过一份申请。申请通过后，系统自动生成合同和首笔订单，并锁定该房源；同一房源其余待审核申请会被拒绝。

## 自动生成合同

申请通过后生成的合同默认从当天开始，期限为一年，月租和押金来自房源信息，初始状态为待生效。租客和房东只能查看与自己相关的合同。房东或管理员可结束合同。

## 首笔订单与支付

申请通过后生成的首笔订单金额为月租加押金，初始状态为待支付。租客只能支付或取消自己的待支付订单，支付方式仅支持微信支付或支付宝支付。订单支付成功后，与订单关联的合同进入履约中状态，房源进入已出租状态。
