# 智能助手与租房偏好

## 智能助手能做什么

智能助手可以搜索真实房源、推荐和对比房源、计算预算、检索平台办理流程，以及按二次确认流程创建看房预约。房源结果来自平台业务接口，知识问答来自本项目知识库。

## 长期租房偏好

长期偏好用于保存稳定的结构化租房条件，例如预算、城市、区域、户型、通勤时长和居住标签。助手只有在用户明确要求记住或保存时才会写入偏好；一次性搜索条件不会自动保存。用户本轮明确提出的条件优先于已保存偏好。

## 会话与隐私边界

短期会话用于理解当前连续对话，并设置有限保存时间。长期偏好不保存密码、访问令牌、身份证号、支付信息或完整聊天记录。用户明确要求清除偏好时，助手才会删除已保存偏好。
